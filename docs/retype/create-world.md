# Create a world

Create a named world with optional TXT or EPUB books. Each book remains a separate import, with its original file and a working text copy saved locally.

## Create the world

1. Open the **Create World** tab. On an empty homepage, you can also use the **Create World** button beneath **Create Your First World**.
2. Enter a **World name**. It cannot be blank. Different worlds may have the same display name.
3. Under **Books (optional)**, choose **Add books** to select one or more `.txt` or `.epub` files. You can add more files or remove a selection using its X button before submitting. Leave this section empty to create a world without books.
4. Choose **Create World**. Wait for preparation to finish. The app creates the world first, then imports the books individually.

When creation and all selected imports succeed, VySol returns to **Worlds** and previews your new world. World cards currently preview the title and artwork; clicking one does not open a detail page, reader, or conversation.

Your draft and selected files survive switching tabs during the session. Reloading or closing the page loses those unsaved selections. After a completed attempt, opening the **Create World** tab again starts a fresh draft. There is not yet a general screen for adding books to an existing world later.

## If a book fails

The form stays open with **Your world is created. Some books need attention.** Read the message beneath each unsuccessful file. The world and successfully imported books remain saved.

Correct the reported problem before choosing **Retry Failed Books**. To replace a file, remove its failed selection with X, then use **Add books** to choose the corrected copy. Retrying uses the existing world and does not resend successful books. Removing a failed selection does not delete any successfully imported book.

For a duplicate-name error, check the [filename rule](reference.md#duplicate-book-names). For encoding or size errors, check [supported books and limits](reference.md#supported-books). Do not recreate the world merely to retry its failed books.

If the app could not confirm an upload, it checks stored import results before permitting a retry. Keep the creation session open so it retains the files and attempt identifiers needed for recovery.

Use the **Worlds** tab whenever you want to return to the collection. The [Reference](reference.md#browsing-worlds) explains search, previews, and display settings.
