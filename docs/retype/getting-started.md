# Getting started

VySol is under active development, and the clean `main` branch is being rebuilt from the project foundations.

## Current source of truth

Use the current repository, tests, and project configuration as the authority for how VySol works.

Older planning material can still be useful as context, but it may contain decisions that were changed or abandoned. Verify planning notes against the current repository before treating them as requirements.

## Documentation

The Retype source lives in `docs/retype/`.

Documentation should describe behavior that exists in the delivered project. Keep plans, experiments, and speculative architecture out of user-facing documentation until they become part of the project.

## Installation

Installation and runtime instructions will be added when the application structure on `main` is established. Avoid copying setup instructions from the archived implementation unless they have been verified against the current project.

## Repository

The source code and issue history live on [GitHub](https://github.com/Vyce101/VySol).
